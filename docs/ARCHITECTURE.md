# Architecture

The reusable core defines identity envelopes and JSON schemas (I0), append-only journals and evidence storage/checkpoints (I1), bounded independent Session/Run authority and synthetic recovery (I2), the existing Windows-native adapter boundary (I3), source-bound causal graphs (I4), provenance ledgers (I5), and admissible-evidence dataset compilation (I6). Their original freezes retain independent identities and validation times.

The I7 engineering runtime composes a registry of fixed providers. A policy-bound document-metadata stage produces an exact verified transfer to the bounded synthetic totals provider. Python API and CLI share workspace guards. Workspace source pins, fresh producer-intent records and per-run outputs preserve local separation; recovery verifies recorded work without redispatch.

The Evidence Engine binds exact source bytes and digests. I4-NEXT projects current causal evidence; I5-NEXT stores prospective attribution with UNKNOWN identities retained. Context Engine v0.1 keeps immutable versioned JSON and source objects; its SQLite query index is disposable and can be rebuilt. It cannot establish independent operational custody or authentic actor/process identity.

The `pg_i7_mcp` stdio server presents ten fixed tools over the API, scoped to a bound workspace. It exposes no arbitrary shell endpoint. The runtime itself starts pinned local Python provider/consumer subprocesses. `agent_clients/llama_cpp_mcp_agent.py` is an independent model-selected MCP client for local models served by llama.cpp; no model weights, server lifecycle manager or benchmark runner is bundled.

The `runtime/candidate/deps/i4_i5` closure is separate from the `src/package_g` historical core selection. Preserve these import roots: the runtime checks exact imported I4/I5 module origins. Do not prepend the historical `src` tree to MCP's import environment.

Public derivative changes sanitize private metadata, disable the private engineering policy and repin selected files. The NEXT loader keeps selected frozen-module/schema checks while refusing unavailable formal native-fixture provenance. The private original remains exact. This is a compatibility adjustment to a selected distribution, not new engines or a new formal freeze.
