# Contributing

Use fresh workspaces and synthetic fixtures. Preserve existing source pins, evidence identities, failure records and no-redispatch recovery. Changes to frozen contracts require a separately identified derivative; never describe them as the original freeze. Contributions intentionally submitted for inclusion use the repository Apache-2.0 terms. Do not submit credentials, private operational evidence, model weights or third-party code without redistribution rights. Document tests and exact scope; engineering checks do not grant operational authority.
