# PGOP1 RUN-001

Status: **PGOP1_RUN_001_PARTIAL_WITH_EXACT_LIMITATIONS**.

PGOP1 is experimental infrastructure for evidence, provenance and advisory claim audits. RUN-001 generalizes its earlier fixed-layout adapter through explicit versioned parsers, source commitments, execution joins, durable processing, and its existing Context Engine. PGOP1 did not solve SWE-bench problems or execute patches/tests in this campaign. I7 remains incomplete and operationally unqualified.

The accessible snapshot contains 25,580 SHA-256-bound files (830,354,973 bytes); 25 protected directories could not be enumerated. Six Full, Lite, Verified and Multilingual dev/test shards contain 3,642 memberships and 2,819 unique instance IDs. Full/Lite/Verified overlaps are retained without counting them as independent problems. Original source bodies are read-only and withheld from redistribution.

We attempted every one of 3,802 declared pertinent accessible files: 1,744 passed a supported narrow parser, 2,045 were explicitly unsupported and 13 returned errors. The initial discovery profile omitted task-validation reference artifacts; an unchanged-code supplemental plan processed 901 reference files and excluded 300 eval.sh scripts from execution. These references are not agent submissions. Source code, generated historical copies and auxiliary assets remain indexed but are not agent trajectories.

The local archive contains 264 JSON trajectories and 266 joined local execution records. Its 266 audits produced 264 INSUFFICIENT_EVIDENCE and 2 INTEGRITY_FAILURE results. The extractor identified 351 statement occurrences: 235 task-completion and 116 issue-resolution predicates. All 351 lack matching benchmark-resolution evidence for their actual predicates, so none is SUPPORTED or CONTRADICTED. Generic completion and component/issue fixes are not silently converted into benchmark success. Other claims may exist outside this bounded extractor, and claims in 300 unsupported Markdown transcripts remain UNKNOWN.

Across public catalogs and the local archive, 77,807 distinct submission/instance record identities were retained. This count represents attributed archived content, not authenticated agent processes. Original agents' reported outcomes are separate from PGOP1 verdicts.

Development used 59 new trajectory IDs. A fixed repository grouping reserved 49 additional cases, but all JSON trajectories share historical submission provenance; this is exploratory repository-heldout evidence, not independent cross-agent generalization. A separate 67-submission catalog partition tests record formats, with no independent claim-language labels. The initial final evaluation occurred once after freezing code; no classifier was tuned afterward. Accuracy, precision and false-positive/false-negative rates are not computed (independent-label denominator zero).

Level B reconstruction used the unmodified official SWE-bench 5.0.2 `_grade` function, pinned local dataset rows and archived patch/log files. It completed 247 of 258 cases: 193 matched archived reports and 54 disagreed (regrade false versus report true). Eleven text-decoding errors remain unavailable comparisons, not negative grades. These discrepancies are preserved. This is not a fresh Docker/test run (Level C NOT_PERFORMED), an exact CLI invocation, or ground truth for the statement extractor.

That native Windows pass is retained as attempt-002. Bounded byte/source analysis found CP1252 marker loss in two sampled discrepancies and reproduced two decode errors; two matching controls were ASCII-only. A separately preregistered full-scope UTF-8 protocol (attempt-003-utf8) used the identical code, official grader and 774 input files, with UTF-8 mode and default encoding asserted before execution. It completed 258 cases without errors: 201 true and 57 false, agreeing with all 258 archived reports. The 54 native discrepancies changed to agreement and the 11 native unavailable cases became comparable. UTF-8 changes both patch and log decoding. Both protocols and all failures remain published; neither comparison measures classifier accuracy or independent benchmark correctness.
