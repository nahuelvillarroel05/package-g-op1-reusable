# Modality A — offline evidence audit plan

DRAFT_NOT_APPROVED. Use inert existing authentic evidence. SOURCE_INTEGRITY checks exact hashes; TASK_BINDING checks exact task/version/run IDs; OUTPUT_PROVENANCE distinguishes source attribution from producer authentication; FUNCTION_CALL_STRUCTURE and FUNCTION_ARGUMENT_VALIDITY check only supplied schemas; PREDICATE_COMPARABILITY checks the actual predicate inputs; CLAIM_EVIDENCE_SUPPORT requires attributable claims and sufficient bound evidence; RECOVERY_INTEGRITY verifies exact retrieved descriptors/bytes.

Process all selected memberships as inventory, including tasks without outputs. Then enumerate output records separately and classify missing/ambiguous/incompatible/eligible. For each eligible predicate produce a decision with task/output/property IDs, code/config/reference hashes, reason, status and evidence. Missing schemas cannot be bypassed using a recovered identity. No tool-call/effect equivalence, publisher boolean as independent truth, or absent expected verdict converted into false_pass=0.

Precommit PGOP1 decision ledgers before official comparisons. Record reference dependencies and prior exposure in contamination ledger. Counters: selected tasks, output occurrences, eligible records, attempted properties, decided properties, supported/contradicted/abstained/errors and exact exclusions, with units separated. No-source tasks are NOT_AUDITED, never silently dropped. All analyzed material is development. Final reporting includes every task and coverage limitation; ingestion alone contributes zero official results.
